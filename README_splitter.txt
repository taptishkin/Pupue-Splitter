Pupue Splitter 3.7 — разделение музыки из игр на отдельные дорожки
==================================================================
ОКНО (стиль Nintendo 3DS)
  Запустите «Pupue Splitter.exe» двойным щелчком (или перетащите файл на
  значок .exe — он сразу откроется в окне).
  * Язык: переключатель EN / RU слева от часов на верхнем экране
    (по умолчанию английский, выбор запоминается).
  * Нижний экран: перетащите сюда файл с музыкой (или «Choose a file…» /
    кнопка SELECT). Появится список дорожек в два столбика (шрифт сам
    уменьшается, чтобы всё влезло) — отметьте нужные («All» / «None»),
    при желании «+ full mix». Для NSF/GBS-плейлистов (.m3u) сверху
    выбирается трек из списка.
  * BPM: после открытия программа сама определяет темп трека — он виден
    на верхнем экране рядом с названием консоли («♩ 125 BPM»). Иногда темп
    может определиться вдвое быстрее/медленнее «нотного» (это одно и то же
    для слуха).
  * Одно окно: если программа уже открыта, файл, открытый из Проводника
    (или ещё один запуск .exe), уходит в уже открытое окно и сразу играет.
  * Плейлист: при открытии файла в списке сверху появляются все
    поддерживаемые файлы из той же папки (для NSF/GBS — треки плейлиста).
    Выбранный трек сразу начинает играть. «◀◀ Prev» / «Next ▶▶» под
    кнопками Play/Stop (и стрелки влево/вправо на крестовине) — предыдущий
    и следующий трек.
  * «Play» / «Pause» (X / START) — играть / пауза, «Stop» (B) — остановить.
    Играет трек, на верхнем экране Коната машет руками
    в такт найденному BPM (руки вверх — на долю).
    Таймлайн на верхнем экране — щёлкните или тяните, чтобы перемотать.
    Громкость — ползунок справа от верхнего экрана (как 3D-слайдер).
  * Живой микс: сразу после открытия программа в фоне готовит все дорожки
    (во временной папке %TEMP%\PupueSplitter, удаляется при выходе).
    Когда они готовы, при прослушивании звучат только отмеченные галочками
    дорожки — галочки можно менять прямо во время игры, а перемотка
    мгновенная. Пока подготовка идёт, играет полный микс (на экране видно
    сколько процентов осталось). Для DS/PS1/SNES/NES/GB это секунды,
    для N64 и GBA — до пары минут на длинный трек.
  * «Change» (Y) — папка, куда сохранять дорожки (по умолчанию — папка
    исходного файла). «Open folder» — показать результат в Проводнике.
  * Формат: WAV / FLAC / MP3 — переключатель рядом с папкой (запоминается).
    WAV — как отрендерено, FLAC — без потерь (примерно вдвое меньше),
    MP3 — 320 кбит/с (с тегом задержки — дорожки остаются синхронными).
  * «Render» (A) — сохранить отмеченные дорожки (если живой микс уже
    подготовлен — мгновенно). Ход работы виден на верхнем экране.
    «Cancel» (B) — прервать. По окончании играет звук «Poupe».
  * HOME — закрыть файл.

КОМАНДНАЯ СТРОКА (как раньше)
  "Pupue Splitter.exe" --cli файл1 [файл2 ...]   или любые параметры ниже
  (-m, -t, -l ...) — тогда программа работает в консоли, без окна.
  Дополнительно: -o <папка> — куда сохранять;  --only "ключ1|ключ2" —
  сохранить только эти дорожки.
  Файл-библиотека (.2sflib / .psflib / .gsflib / .usflib) должен лежать рядом.

  .mini2sf / .2sf   (Nintendo DS)
      -> по WAV на каждый трек секвенции, рядом с исходным файлом:
         "<песня> - Track NN (prg P).wav"  (prg = номер инструмента в банке)
  .minipsf / .psf   (PlayStation)
      -> по WAV на каждый сэмпл-инструмент (как у N64):
         "<песня> - Inst NN (smp XXXXX).wav"  (smp = адрес сэмпла в памяти SPU)
         Голоса SPU игра раздаёт нотам как попало, поэтому программа следит,
         какой сэмпл играет каждый голос, и собирает всё, что звучит этим
         сэмплом, в одну дорожку — со своей долей реверберации.
         Сумма всех файлов = оригинальный микс. (Старый режим «по голосам»
         остался только в командной строке: параметр --psf-voices.)
  .miniusf / .usf   (Nintendo 64)
      -> по WAV на каждый сэмпл-инструмент, рядом с исходным файлом:
         "<песня> - Inst NN (smp XXXXXX).wav"
         Игры N64 раскидывают ноты по голосам динамически, поэтому деление
         идёт по сэмплу (кодбук ADPCM), который играет голос. Песня
         эмулируется отдельно для каждого инструмента, так что у каждой
         дорожки своё родное эхо/реверб игры. 44100 Гц (параметр -r).
         Разделение работает для игр со стандартным аудио-микрокодом
         libultra (ABI1 и "naudio"; проверено на Banjo-Kazooie). Для игр
         с другим микрокодом программа сообщит об этом и сохранит только микс.
         Длинные треки считаются несколько минут (один проход на инструмент).
  .spc              (SNES)
      -> по WAV на каждый из 8 голосов DSP, рядом с исходным файлом:
         "<песня> - 01 DSP 1.wav" ... Каждый голос со своей долей эха.
         Неиспользуемые голоса пропускаются.
  .vgm / .vgz       (Sega Mega Drive / Genesis и другие VGM)
      -> по WAV на каждый канал чипа, рядом с исходным файлом:
         FM 1-6 (YM2612), PCM (сэмплы/ударные через DAC), PSG 1-3, PSG Noise.
         Длина: вступление + 2 повтора петли, затем затухание 10 с.
  .nsf / .nsfe      (NES)
  .gbs              (Game Boy)
      -> по WAV на каждый звуковой канал, рядом с исходным файлом:
         NES: Square 1, Square 2, Triangle, Noise, DMC (+ каналы чипов
         расширения VRC6/VRC7/FDS/MMC5/N163/5B, если они есть в игре);
         Game Boy: Square 1, Square 2, Wave, Noise.
         В таких файлах много треков сразу. Программа показывает список
         (названия и длины берутся из .m3u-плейлиста рядом, если он есть)
         и спрашивает, какие треки разделить: например 5, или 2,7,10-12,
         Enter = все. Без вопроса: параметр -t (см. ниже).
  .m3u              (плейлист для NSF/GBS)
      -> можно перетащить сам плейлист: будут разделены треки из него
         (если в нём один трек, например "02 Stage 1 - Green Greens.m3u",
         то сразу этот трек, с длиной и затуханием из плейлиста).
  .minigsf / .gsf   (Game Boy Advance, движок MP2K/"Sappy")
      -> папка "<песня> - stems": 00_full_mix.wav + дорожки (как в GSF Splitter 1.0)

Длина и затухание берутся из тегов файла. Все файлы одной песни одинаковой
длины и синхронны — их можно сразу класть в DAW.

Параметры командной строки:
  -l 2:30   длина, если в файле нет тега length
  -f 10     длина затухания (сек)
  -m        2SF/PSF/USF/SPC/VGM/NSF/GBS: дополнительно сохранить полный микс
  -t 2,7    NSF/GBS/плейлисты: какие треки разделить без вопроса (5 / 2,7,10-12 / all)
  -r 48000  частота для 2SF/GSF/USF/SPC/VGM/NSF/GBS (PSF всегда 44100 — родная частота PS1)
  -q        не ждать Enter в конце

Ядра эмуляции/проигрывания:
  DS:  SSEQ Player (Naram Qashat / FeOS Sound System, WTFPL), с поправками
  PS1: Highly Experimental (Neill Corlett, GPLv3) + захват по голосам
  GBA: mGBA (MPL-2.0)
  SNES/VGM/NES/GB: Game_Music_Emu (blargg, kode54; LGPL), SPC через higan SMP + SPC_DSP
  N64: lazyusf2 (kode54, на основе mupen64plus, GPL) + захват голосов в HLE-аудио
Вся программа распространяется на условиях GPLv3; исходный код —
Pupue_Splitter_source.zip.

Кодеки: FLAC — libFLAC (Xiph, BSD), MP3 — LAME 3.100 (LGPL).
